# قواعد قعدة

مستودع مشروع «قعدة» لإياد حلوبي.

## المحتوى
- **`qa3da-builder/`**: مهارة «بناء قعدة» لـClaude. بتبني أي قعدة جديدة من العيلات الأربع حسب «قواعد قعدة» ودليل الهوية.
  - `qa3da-builder/references/rules.md`: **قواعد قعدة** (المرجع الأول، محدّث).
  - `qa3da-builder/references/`: الهوية، العيلات، دليل البناء الفردي والجماعي، قائمة الفحص قبل التسليم.
  - `qa3da-builder/assets/`: اللوغو، الكراسي، الخطوط، والقالب الجماعي.
- **`akher-wahed/`**: «قعدة آخر واحد» (12 لعبة إقصاء جماعية) بعد مراجعتها على القواعد.

## رفع «آخر واحد» على Render
من Render اختار **New → Blueprint** واربطه بهالمستودع. ملف `render.yaml` بأول المستودع بيبني من مجلد `akher-wahed` وبيولّد مفتاح الإدارة `ADMIN_KEY`.

قبل الرفع: حط رابط ريل القعدة بـ`REEL_URL` بأول `akher-wahed/public/app.js`.
