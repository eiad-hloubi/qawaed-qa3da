# قبل أي تسليم

مرّ على كل بند وجرّبه فعلياً بالمتصفح (Playwright). ما تكتب «تم» لبند ما جرّبته.

## الكل
- [ ] **فوق:** اللوغو العادي، والرجوع، والبيت ظاهرين، وكود القعدة ظاهر إذا جماعي. ولا كرسي ولا اسم عيلة بالإطار.
- [ ] **زر «⋯»** بيفتح وبيسكّر، وكل اللي جوّاته شغّال: قدّام، وحسابي، وفاتح وداكن، والتعليمات.
- [ ] **الزر الصغير** بيخبّي القائمة وبيرجّعها. لما تكون مخفية أعلى المحتوى عند 0 (بلا فراغ)، وبتطلع لما المؤشر يقرّب من فوق وبتنسحب لما يبعد.
- [ ] **البيت:** جماعي بخياراته التلاتة (بنفس الناس، أو بناس جدد، أو من الصفر). فردي: «ابدأ من جديد» مع تأكيد.
- [ ] **رجوع:** خطوة وحدة والجواب محفوظ. **قدّام:** بيرجع لمكانه.
- [ ] **التعليمات:** بتبلّش بكرسي العيلة واسمها، وفيها الخطوات والحساب والمرجع، وبتخلص بـ«إعداد م. إياد حلوبي». وما بتطلع لحالها.
- [ ] **الغلاف:**
  - الأيقونة، والاسم المباشر بخط العيلة، وسطر الوصف، و«إعداد م. إياد حلوبي».
  - موشن مستمر ومش لون مصمت.
  - شريط متحرك (مستقيم بلمّة وألفة).
  - زر البداية، والمدة، و«نزّل التطبيق» مع خطوات الآيفون والأندرويد واللابتوب.
- [ ] **الاسم والصورة:**
  - من البداية للنتيجة، مع اسم وصورة وبدونهن.
  - الحقل فاضي قبل النتيجة.
  - `?n=` بيعبّي الاسم.
- [ ] **الصورة:** سيلفي ومعرض، وقص وتكبير وسحب لكل الحواف، وتدوير وقلب، وتعديل لاحق من «حسابي».
- [ ] **الصورة نضيفة:** لا تعتيم ولا ظل فوق الصورة بشاشة القص ولا بعدها (دليل القص خط رفيع بس)، والكاميرا بتستنى تجهز قبل التصوير.
- [ ] **الواجهة مش معجوقة:** كل شاشة إلها زر أساسي واحد، والإعدادات الثانوية مطوية.
- [ ] **الستوري:**
  - 3 أشكال × فاتح وداكن، و1080×1920.
  - اسم قصير وطويل (متل «عبد الرحمن الشامي») بلا تداخل.
  - 250px آمنة فوق وتحت.
  - تحت بس `@eyad.hloubi` و`#qa3da` بزاويتين. لا أيقونة، ولا كرسي، ولا «صار بدها قعدة»، ولا اسم إياد مرتين.
- [ ] **شارك مع صحابك:** بيبعت `REEL_URL` (ريل القعدة).
- [ ] **الفاتح والداكن** بكل الشاشات وبالستوري.
- [ ] **الأرقام** إنجليزية بكل مكان.
- [ ] **اللغة:** بيضا بالفردي، وشامية بالجماعي، بلا خلط.
- [ ] **الأجهزة:** موبايل 360px وتابلت ولابتوب، لمس وماوس، بلا سكرول أفقي.
- [ ] **المحتوى:** ما بيجرح (الشكل، والوزن، والدين، والمصاري الحقيقية)، وبيوافق العقيدة بلا وعظ مباشر.

## الأسئلة (إذا في)
- [ ] الخيارات مخربطة لكل سؤال ولكل شخص (إلا المقاييس العلمية).
- [ ] كل نتيجة إلها حصة متساوية. جرّب بسكربت يحسب الأوزان الممكنة.
- [ ] الصياغة مموّهة، وما في خيار بيفضح وجهته.
- [ ] حد أقصى خيارين مرتّبين، ووزن السؤال ثابت.
- [ ] المحور والمرحلة وكم سؤال باقي ظاهرين.
- [ ] كل النسب بالنتيجة ظاهرة، والنصيحة بتتغيّر مع الفروق البسيطة.

## الفردي
- [ ] ملف HTML واحد، وبيشتغل من `file://` بلا نت (الخطوط مضمّنة).
- [ ] **التخطيط:** حفظ عالجهاز، وتصدير واستيراد ملف، ونسخة أوفلاين.
- [ ] **الاستبيان:** نسخة أوفلاين.

## الجماعي
- [ ] **الدخول:** QR، ورابط (نسخ ومشاركة)، وكود من 5 أحرف.
- [ ] **«جاهز»:** بيبين كل اللاعبين مين جاهز ومين لسا (حتى مع 12 لاعب)، والبداية بعدّ تنازلي سوا.
- [ ] **شب أو صبية** إجباري، والنصوص والألقاب بتتأنّث.
- [ ] **صورة الشلة واسم القعدة ونوعها** (تحدّي ولعب، ولمّة وألفة).
- [ ] **فردي وفرق** (2–4، بقائد، والنتيجة متوسط) بكل قعدة جماعية، إلا إذا الطلب قال صراحة لأ. جرّب جولة كاملة بالفرق.
- [ ] **التطليع، وتسليم الريس، واستلام الريس** إذا غاب.
- [ ] **الرجوع:**
  - تلقائي بعد انقطاع النت أو التحديث.
  - زر «العودة» إذا طلع كلياً ورجع.
- [ ] **«اسمي»** مميّز بكل القوائم.
- [ ] **أدوات الريس:** «سكّر هلأ»، و«خلّصنا»، و«قعدة جديدة»، و«تمرير»، و«إعادة»، وكلها مجرّبة.
- [ ] **التعادل** صح.
- [ ] **الكشف** بالخيارات التلاتة، و**الخيار بيطلع للريس بعد ما تخلص الألعاب** (مش باللوبي).
- [ ] **إعداد الريس:** اسمه وصورته، وبعدها مباشرة بنفس الشاشة اسم القعدة ونوعها وصورة الشلة.
- [ ] **الإعادة:** إلعب لعبة، أعدها بنتيجة مختلفة، وتأكد إنو الترتيب والمجموع النهائي بياخدوا نتيجة الإعادة بس.
- [ ] **إيموجيات التفاعل** آخر كل لعبة (3–4 بس)، بتطير عند الكل.
- [ ] **«كيف منلعب»:** كادر واسع، وسطر واحد قصير تحته. «اختبر الصوت» بس بألعاب الصوت.
- [ ] **ألعاب المايك** بالمايك بس (بلا بديل لمس)، مع معايرة مريحة للمايكات الضعيفة.
- [ ] **الجويستيك:** بيبلّش من مكان الإصبع، ومنطقة لمس كبيرة.
- [ ] **الوضوح البصري:** كل شي بيأثّر عالنتيجة ظاهر (مين أقوى، مين قعد)، ولا عنصر بيغطّي اللعب، ولا عنصر زايد أو ناقص.
- [ ] **أسباب الطلعة والرسائل** بتتأنّث للصبايا وبتنجمع للمجموعة (بلا «خسر/ت»).
- [ ] **الصوت:** للدولاب والعدّ والكشف والفوز، مع تنبيه «علّي صوت الموبايل».
- [ ] **«كيف منلعب»** (تحدّي ولعب): موشن بسيط بشاشة جاهز، وكلام قصير.
- [ ] **ما في وضع تجربة** ولا لاعبين وهميين باللعب الحقيقي.
- [ ] **الخصوصية:** ما بيبين مين صوّت لمين.
- [ ] **الصور ما بتنكتب على السيرفر**، و`/stats` و`/admin` أرقام بس.
- [ ] **الحزمة:** `render.yaml` و`Dockerfile` و`README.md` بالعربي، والخطوط والأيقونات مستضافة معها.

## أيقونة التنزيل
- [ ] مربع كامل بلون العيلة (درجة 700)، بلا زوايا وبلا شفافية.
- [ ] التكوين 64% بالنص.
- [ ] `any` (192 و512) و`maskable` (512) منفصلين، و`apple-touch-icon` 180.
- [ ] مجرّبة بقناع دائرة وقناع مربع مدوّر، وما في ولا حرف ناقص.
